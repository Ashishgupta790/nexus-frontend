# NEXUS

NEXUS is an interactive developer workspace combining project management, documents, global search, activity tracking and a visual workflow editor.

## Stack

- React + TypeScript + Vite
- Tailwind CSS
- Redux Toolkit + React Redux
- React Router
- Motion
- @xyflow/react
- Lucide React
- React Hook Form
- Recharts-ready architecture
- Zod-ready architecture
- clsx + tailwind-merge

## Run

```bash
npm install
npm run dev
```

Then open the Vite URL.

## Included

- Landing page
- Local frontend authentication
- Protected application shell
- Dashboard
- Projects + project details
- Visual workflow editor
- Node library + inspector
- Workflow execution animation
- Documents
- Activity
- Global search / command palette (Ctrl/⌘ + K)
- Settings
- Light/dark/OLED preference state
- Responsive layout
- Redux slices and structured mock data

The backend is intentionally not required for this first frontend build. The data layer is isolated so REST APIs can replace mock data later.
